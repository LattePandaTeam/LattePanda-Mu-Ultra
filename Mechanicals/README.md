# Mechanical Files

Drawings and models of LattePanda Mu Ultra compute module for structural design use.

## Files

- [**LattePanda Mu Ultra Dimension Drawing.pdf**](<./LattePanda Mu Ultra Dimension Drawing.pdf>): LattePanda Mu Ultra dimension drawing, PDF format
- [**LattePanda Mu Ultra Dimension Drawing.dxf**](<./LattePanda Mu Ultra Dimension Drawing.dxf>): LattePanda Mu Ultra dimension drawing, DXF format
- [**LattePanda Mu Ultra 3D Model.stp**](<./LattePanda Mu Ultra 3D Model.stp>): 3D model of LattePanda Mu Ultra, STEP format, which can be used directly in PCB design
- For the mechanical files of **various official carrier boards**, please visit: 👉 [**LattePanda-Mu/Mechanicals/Carrier-Boards**](https://github.com/LattePandaTeam/LattePanda-Mu/tree/main/Mechanicals/Carrier-Boards).
