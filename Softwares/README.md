# Software Resources

Within this repository, you will find a range of software resources specifically related to the LattePanda Mu Ultra, including BIOS firmware, drivers, etc.

Please be aware that this repository is dedicated to providing materials relevant to the LattePanda Mu Ultra. For firmware and drivers related to carrier boards, refer to the respective carrier board documentation pages for more details.

## Resource Categories

- **BIOS**: Contains stable and beta BIOS updates officially supported.

- **Drivers**: Drivers and related descriptions.
